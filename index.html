        📖How to Read NexariOS
        ☄️ HR Signals
        Round-robin interleaved across all games — the top pick from each game appears before any game's second pick. Each card shows: Tier · OCM score · Live DraftKings odds · EV/Barrel/ISO stats (when available from KV) · Career HR vs this pitcher (🏠 badge appears when 2+ career HRs).
        Strong18%+ HR probability — highest confidence.
        Medium11–17% probability — solid situational play.
        LightUnder 11% — value plays only.
        ⚾️ Games
        Browse any date with ◀ ▶. Tap any game to expand. Confirmed batting order shows numbered slots 1–9. Final games show H/HR/RBI per batter and K for the starter.
        📊 Accuracy
        Tracks ALL tiers — Strong, Medium, and Light picks are all saved on each signals load. Outcomes are computed automatically the next day from MLB boxscores. System Tracker shows tier-by-tier breakdown (picks · hits · misses · %) so you can see which tier performs best over time.
        🔍 Search
        Search any player or team. Results show OCM, tier, opponent, and pitcher for the current date.
