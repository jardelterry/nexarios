        📖How to Read NexariOS
        ☄️ HR Signals
        Ranks batters from across the full day's slate by HR likelihood. Uses round-robin interleaving so the top pick from each game appears before the 2nd pick from any game — you always see variety at the top, not a cluster from one matchup.
        Strong 18%+ HR probability. Highest confidence — prioritize for single-game props and parlay legs.
        Medium 11–17% probability. Solid situational play — good for longer-odds parlays.
        Light Under 11%. Low confidence — only play when odds offer significant value.
        OCM 0–100 composite: batter power (HR rate, SLG, OPS) vs pitcher vulnerability (ERA, HR allowed).
        ⚾️ Games
        Use ◀ ▶ to browse any date. Tap any game to expand rosters. When lineups are officially confirmed (usually 3–4 hours pre-game), batting order numbers appear next to each player — 1 through 9. For live and final games, the boxscore batting order is used. Final games also show H / HR / RBI per batter and K for the starting pitcher.
        📊 Accuracy
        No setup required. Every time you load HR Signals, the system automatically saves today's Strong picks to KV. The following day, outcomes are computed automatically from MLB boxscores. System Tracker accumulates over time. Season Leaders pull live from MLB Stats API each load.
        🔍 Search
        Search any player or team name. Results show OCM, tier, opponent, and pitcher for today's slate.
