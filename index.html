NexariOS v6.6 — System Guide

HR View (Home Run Signals)
Nexari ranks hitters using the Overmind Composite Metric (OCM), a probability‑driven score built from:
• Lineup position
• Park factor
• Temperature
• Wind direction
• Weather conditions
• Venue characteristics
• System‑calibrated HR base values

The HR tab shows:
• Player
• Team vs Opponent
• Sportsbook odds
• HR Base
• OCM score
• Tier ring (Strong / Playable / Watch)
• Momentum bar

The list is always sorted by highest probability first.
Use the dropdown to view Top 10, Top 20, or All.

Games View
Shows:
• Matchups
• Game time
• Weather
• Lineups
• Scores
• Status

A compact LIVE ticker appears at the top of this page only, showing all live games with scores.

Accuracy View
Tracks Nexari’s performance:
• Daily accuracy
• 7‑day trend
• 30‑day trend
• Prediction volume
• HR hitters that actually hit today

• Notes

This keeps the HR tab clean and minimal.
